Streamlit · OpenRouter

Registro general

Verifica Cédula de Ciudadanía, Serial de Dron o Batería/Componente a partir de una foto, y guarda el registro verificado en una base de datos local.

Cómo correrlo: instalá dependencias y arrancalo desde la raíz del repo: pip install -r requirements.txt y streamlit run app.py
Abrir módulo (localhost:8501)
FastAPI · OpenRouter

Verificación de Serial de Dron

Compara el serial escrito por el usuario contra el que lee una IA en la foto de la etiqueta del dron, con umbral de similitud ajustable y log de cada intento.

Cómo correrlo: backend y frontend por separado (dos terminales), dentro de modulo-verificacion-dron/: cd backend && python -m uvicorn main:app --reload y en otra terminal cd frontend && python -m http.server 5501
Abrir módulo (localhost:5501)
